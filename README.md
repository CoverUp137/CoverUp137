## 👋 关于我

- 🏠 **自托管派**：一台 N100 小主机（Debian + Docker）跑 Vaultwarden / MySQL / Nginx，配 R2 异地备份，顺手写成一键部署脚本——自己用的东西，也要能给别人一条命令用起来
- 📶 **网络折腾党**：OpenWrt / 软路由常客，AX6S、N60pro 固件自己编，Clash 规则、订阅转换模板自己写
- ☁️ **Cloudflare Workers 爱好者**：GitHub 加速、Docker 镜像反代、订阅转换，能放在边缘跑的就放边缘
- 🤖 **能自动化的绝不手动**：固件编译、KernelSU 修补、面板备份，统统交给 GitHub Actions

> ⚡ 座右铭：**能自动化的，绝不手动。**
